# IDA Pro Legacy Dumper (Archived)

This directory contains the historical IDA Pro (7.1+) Hex-Rays decompiler script for dumping packet and event structures.

> **Status: Archived & Unsupported**
> This implementation is retained solely as a historical reference and for parity/audit comparisons with the active native Rust dumper (`dumper_rust/`). It is not actively maintained.
